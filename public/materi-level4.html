Level 4

🔁 Perulangan (Loops)

Memahami konsep loop, tiga jenis perulangan yang tersedia, serta cara menghentikan atau melewati putaran dengan break dan continue.

🔁 Mengapa Perlu Perulangan?

Bayangkan kamu ingin mencetak "Halo!" sebanyak 100 kali. Tanpa perulangan, kamu harus membuat 100 blok print — sangat tidak efisien! Dengan perulangan (loop), kamu cukup menulis satu blok print dan memberi tahu komputer untuk mengulanginya.

🎯
Analogi Sederhana

Perulangan itu seperti perintah: "Ulangi langkah berikut 10 kali: lompat ke depan." — Kamu tidak perlu menulis "lompat" sepuluh kali, cukup beri instruksi satu kali dengan jumlah pengulangan.

Keuntungan menggunakan loop:

  • Kode menjadi lebih pendek dan rapi
  • Mudah diubah — cukup ganti angka pengulangannya
  • Mengurangi kesalahan — tidak perlu copy-paste blok berulang kali
  • Bisa menangani data dalam jumlah besar secara otomatis

🔄 Tiga Jenis Perulangan

Di Blockly, ada tiga jenis blok perulangan yang masing-masing cocok untuk situasi yang berbeda:

1️⃣ Repeat ... Times

Mengulangi blok di dalamnya sejumlah kali tertentu yang sudah diketahui. Ini adalah jenis loop paling sederhana.

📌
Kapan dipakai?

Ketika kamu tahu pasti berapa kali ingin mengulangi sesuatu. Contoh: "Cetak bintang 5 kali", "Lakukan operasi ini 3 kali".

🧩 Blockly
repeat 5 times
print "⭐"
🐍 Python
for count in range(5):
    print("⭐")

2️⃣ Count With / For (Rentang Angka)

Mengulangi blok dengan sebuah variabel penghitung yang bergerak dari angka awal ke angka akhir. Kamu bisa menggunakan variabel penghitung ini di dalam blok.

📌
Kapan dipakai?

Ketika kamu butuh nomor urut atau ingin melakukan sesuatu pada rentang angka tertentu. Contoh: "Cetak angka 1 sampai 10", "Hitung mundur dari 10 ke 1".

🧩 Blockly
count with i from 1 to 5
print i
🐍 Python
for i in range(1, 6):
    print(i)
# Output: 1, 2, 3, 4, 5
⚠️
Perhatikan range() di Python!

Di Python, range(1, 6) menghasilkan angka 1 sampai 5 (bukan 6!). Angka terakhir tidak termasuk. Blockly menangani konversi ini secara otomatis untukmu.

3️⃣ While (Selama Kondisi Benar)

Mengulangi blok selama kondisi tertentu masih bernilai True. Loop akan berhenti saat kondisi menjadi False.

📌
Kapan dipakai?

Ketika kamu tidak tahu pasti berapa kali harus mengulang, tapi tahu kapan harus berhenti. Contoh: "Terus minta input sampai pengguna mengetik 'quit'", "Ulangi sampai skor mencapai 100".

🧩 Blockly
set angka to 1
while angka ≤ 5
print angka
set angka to angka + 1
🐍 Python
angka = 1
while angka <= 5:
    print(angka)
    angka = angka + 1
# Output: 1, 2, 3, 4, 5
⚠️
Hati-hati: Infinite Loop!

Jika kondisi while tidak pernah menjadi False, loop akan berjalan selamanya (infinite loop) dan program akan macet! Pastikan ada mekanisme yang membuat kondisi berubah menjadi False.

⏹️ Break dan Continue

Kadang kamu butuh kontrol lebih dalam perulangan — bisa menghentikannya lebih awal atau melewati putaran tertentu. Ada dua perintah khusus untuk ini:

Perintah Fungsi Analogi
break Menghentikan seluruh perulangan secara langsung, keluar dari loop Seperti menekan tombol "STOP" — perulangan langsung selesai, lompat ke kode setelah loop
continue Melewati satu putaran saat ini, lanjut ke putaran berikutnya Seperti "skip" — lewati putaran ini, tapi lanjutkan looping

Contoh penggunaan break: Mencari angka tertentu dalam rentang, dan berhenti begitu menemukannya.

Contoh penggunaan continue: Mencetak semua angka kecuali angka tertentu (lewati angka yang tidak diinginkan).

👀 Contoh: Blockly ↔ Python

Berikut contoh program yang mencetak angka 1 sampai 10, tapi melewati angka 5 dan berhenti di angka 8:

🧩 Blok Blockly
count with i from 1 to 10
if i = 5
continue
if i = 8
break
print i
🐍 Kode Python
for i in range(1, 11):
    if i == 5:
        continue
    if i == 8:
        break
    print(i)

# Output: 1, 2, 3, 4, 6, 7
# (5 dilewati, berhenti di 8)
🎓
Perhatikan!

Angka 5 tidak tercetak karena continue melewatinya. Angka 8, 9, 10 tidak tercetak karena break menghentikan seluruh loop saat i = 8. Urutan pengecekan if sangat penting!
