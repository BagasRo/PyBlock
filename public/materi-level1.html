🖨️ Output, Teks, Angka & Input

Belajar mencetak ke layar, mengenal tipe data dasar, operator aritmatika, dan menerima masukan dari pengguna.

🖨️ Mencetak ke Layar dengan print

Perintah paling dasar dalam pemrograman adalah menampilkan sesuatu ke layar. Di Python, kita menggunakan fungsi print() untuk melakukan hal ini.

Di Blockly, blok "print" ada di kategori Output. Kamu cukup menyambungkan blok yang ingin dicetak ke dalam lubang blok print, dan hasilnya akan muncul di Console.

💡
Mengapa print penting?

Print adalah cara utama kita "berkomunikasi" dengan pengguna. Tanpa print, program kamu berjalan tapi tidak menampilkan apa-apa — seperti berbicara tanpa suara!

🔤 Blok Teks (String) dan Blok Angka

Dalam pemrograman, data memiliki tipe. Dua tipe paling dasar yang akan kamu temui:

  • Teks (String) — Deretan karakter yang diapit tanda kutip. Contoh: "Halo", "Python itu seru"
  • Angka (Number) — Nilai numerik yang bisa dihitung. Contoh: 42, 3.14

Di Blockly, blok teks berwarna hijau toska dan blok angka berwarna biru keunguan. Perbedaan warna ini membantu kamu membedakan tipe data secara visual.

⚠️
Hati-hati!

Teks "10" dan angka 10 itu berbeda! Teks "10" tidak bisa dihitung, sedangkan angka 10 bisa. Pastikan kamu menggunakan tipe yang tepat sesuai kebutuhan.

🔢 Enam Operator Aritmatika

Operator aritmatika digunakan untuk melakukan perhitungan matematika pada angka. Di Blockly, blok operasi matematika tersedia di kategori Math:

Operator Nama Contoh Hasil
+ Penjumlahan 5 + 3 8
- Pengurangan 10 - 4 6
* Perkalian 6 * 7 42
/ Pembagian 15 / 4 3.75
^ Pangkat 2 ^ 3 8
% Modulo (sisa bagi) 10 % 3 1
📌
Apa itu Modulo?

Modulo (%) mengembalikan sisa pembagian. Contoh: 10 ÷ 3 = 3 sisa 1, jadi 10 % 3 = 1. Sangat berguna untuk mengecek bilangan genap/ganjil!

⌨️ Tiga Blok Input

Input memungkinkan program menerima masukan dari pengguna. Di Blockly, ada tiga jenis blok input yang berbeda tergantung tipe data yang ingin diterima:

Blok Input Fungsi Kapan Dipakai Contoh Masukan
read text Membaca input sebagai teks (string) Saat meminta nama, alamat, kata "Budi"
read int Membaca input sebagai bilangan bulat Saat meminta umur, jumlah, kuantitas 25
read float Membaca input sebagai bilangan desimal Saat meminta harga, berat, suhu 3.14
⚠️
Pemilihan Blok Input yang Tepat

Jika soal meminta pengguna memasukkan angka untuk dihitung, gunakan read int atau read float. Jangan gunakan read text karena teks tidak bisa dioperasikan secara matematis!

👀 Contoh: Blockly ↔ Python

Berikut contoh sederhana program yang meminta pengguna memasukkan dua angka, lalu mencetak hasil penjumlahannya:

🧩 Blok Blockly
🐍 Kode Python
print("Masukkan angka pertama:")
a = int(input())
print("Masukkan angka kedua:")
b = int(input())
print(a + b)
🎓
Perhatikan!

Setiap blok di sisi kiri menghasilkan satu baris kode di sisi kanan. Dengan memahami hubungan ini, kamu akan mulai bisa membaca dan menulis kode Python secara mandiri!
