📦 Variabel & Pengelolaan Data

Memahami variabel sebagai wadah nilai, cara membuat dan memperbarui data, serta menggabungkan teks dengan angka.

📦 Apa Itu Variabel?

Variabel adalah wadah atau kotak penyimpanan yang digunakan untuk menyimpan nilai di dalam program. Setiap variabel memiliki nama dan isi (nilai).

🎯
Analogi Sederhana

Bayangkan variabel seperti kotak berlabel. Kamu punya kotak berlabel "umur" yang berisi angka 17. Kapan pun kamu butuh angka itu, kamu cukup mengambilnya dari kotak "umur" — tidak perlu mengingat angkanya!

Mengapa variabel dibutuhkan? Tanpa variabel, kamu harus menuliskan angka atau teks secara langsung setiap kali dipakai. Ini akan sangat merepotkan, terutama jika:

  • Nilai yang sama dipakai berkali-kali di banyak tempat
  • Nilai bisa berubah (misalnya dari input pengguna)
  • Kamu ingin menyimpan hasil perhitungan untuk dipakai nanti

✏️ Membuat Variabel: Blok Set & Get

Di Blockly, ada dua blok utama untuk bekerja dengan variabel:

Blok Fungsi Penjelasan
set [variabel] to Mengisi / mengatur nilai variabel Seperti memasukkan benda ke dalam kotak. Jika kotak belum ada, ia akan dibuat secara otomatis.
get [variabel] Mengambil / membaca nilai variabel Seperti mengintip isi kotak tanpa mengeluarkannya. Nilai tetap tersimpan di variabel.

Langkah membuat variabel baru di Blockly:

  1. Buka kategori Variables di toolbox
  2. Klik tombol "Create Variable"
  3. Beri nama variabel (contoh: nama, umur, total)
  4. Gunakan blok set untuk mengisi nilainya dan blok get untuk memanggilnya
⚠️
Tips Penamaan Variabel

Beri nama variabel yang deskriptif dan mudah dipahami. Gunakan luas_segitiga daripada x, agar kode lebih mudah dibaca dan dipahami.

🔄 Memperbarui Nilai Variabel

Variabel bisa diubah nilainya kapan saja selama program berjalan. Ini disebut reassign (penugasan ulang). Nilai lama akan digantikan oleh nilai baru.

🧩 Konsep Reassign
set skor to 0
print skor
set skor to 100
print skor
🐍 Output
# Output yang dihasilkan:
0      # nilai awal
100    # setelah diubah

Kamu juga bisa mengakumulasi nilai variabel, yaitu mengubah nilainya berdasarkan nilai sebelumnya. Contoh: menambahkan skor setiap kali pemain menjawab benar.

💡
Pola Akumulasi

Pola set skor to (skor + 10) artinya: "ambil nilai skor saat ini, tambahkan 10, lalu simpan kembali ke skor." Ini sangat berguna untuk menghitung total, rata-rata, atau penghitungan apapun yang bertahap.

🔗 Menggabungkan Angka dengan Teks

Sering kali kamu ingin mencetak pesan yang menggabungkan teks dan angka. Misalnya: "Umur kamu adalah 17 tahun". Untuk melakukan ini di Blockly, ada dua blok penting:

Blok Fungsi Penjelasan
create text with Menggabungkan beberapa potongan teks menjadi satu Seperti menyambung potongan puzzle teks. Kamu bisa menambah slot sebanyak yang dibutuhkan.
to str Mengubah angka menjadi teks Diperlukan sebelum menggabungkan angka ke dalam teks, karena teks dan angka adalah tipe data yang berbeda.
🔑
Mengapa perlu to str?

Dalam Python, kamu tidak bisa langsung menggabungkan teks dengan angka menggunakan +. Angka harus dikonversi menjadi teks dulu menggunakan str(). Blok to str otomatis melakukan konversi ini untukmu.

👀 Contoh: Blockly ↔ Python

Berikut contoh program sederhana yang menyimpan angka (skor) lalu menggabungkannya dengan teks untuk dicetak:

🧩 Blok Blockly
set skor to 100
print create text with "Skor: " + str(skor)
🐍 Kode Python
skor = 100
print("Skor: " + str(skor))
🎓
Perhatikan!

Variabel skor yang berisi angka harus diubah menjadi teks dengan str(skor) sebelum bisa digabungkan ke dalam kalimat. Jika tidak, akan terjadi error karena komputer tidak tahu cara menyatukan huruf dan angka secara langsung.
