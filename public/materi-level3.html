🔀 Boolean, Perbandingan & Percabangan

Memahami nilai boolean, operator perbandingan, struktur pengambilan keputusan if/else, dan operator logika.

🔲 Konsep Nilai Boolean

Boolean adalah tipe data yang hanya memiliki dua kemungkinan nilai:

  • True — artinya benar atau ya
  • False — artinya salah atau tidak

Boolean adalah dasar dari semua pengambilan keputusan dalam pemrograman. Setiap kali program harus memilih jalur yang berbeda (misalnya: "apakah nilai lulus atau tidak?"), ia menggunakan boolean untuk menentukan jawabannya.

🎯
Analogi Sederhana

Boolean itu seperti saklar lampu — hanya bisa ON (True) atau OFF (False). Tidak ada posisi tengah! Dalam pemrograman, kondisi hanya bisa benar atau salah.

⚖️ Enam Operator Perbandingan

Operator perbandingan digunakan untuk membandingkan dua nilai dan menghasilkan boolean (True atau False). Di Blockly, blok perbandingan ada di kategori Logic:

Operator Arti Contoh Hasil
= Sama dengan 5 = 5 True
≠ Tidak sama dengan 5 ≠ 3 True
< Kurang dari 3 < 7 True
> Lebih dari 3 > 7 False
≤ Kurang dari atau sama dengan 5 ≤ 5 True
≥ Lebih dari atau sama dengan 3 ≥ 5 False
📌
Di Python

Operator "sama dengan" di Python ditulis == (dua tanda sama), bukan satu. Tanda = tunggal dipakai untuk mengisi variabel, sedangkan == dipakai untuk membandingkan. "Tidak sama" ditulis !=.

🔀 Struktur If dan If/Else

Struktur if adalah cara program mengambil keputusan. Program akan memeriksa sebuah kondisi (yang bernilai True atau False), lalu menjalankan kode tertentu hanya jika kondisi tersebut terpenuhi.

1. Struktur if saja:

Jika kondisi True, jalankan blok di dalamnya. Jika False, lewati saja.

2. Struktur if/else:

Jika kondisi True, jalankan blok pertama. Jika False, jalankan blok alternatif (else).

🎯
Analogi Sederhana

Struktur if/else itu seperti persimpangan jalan. "Jika hujan → bawa payung, Jika tidak hujan → pakai kacamata hitam." Program memilih satu jalur berdasarkan kondisi saat itu.

🧠 Operator Logika: AND, OR, NOT

Operator logika digunakan untuk menggabungkan atau membalik syarat (kondisi boolean). Dengan operator logika, kamu bisa membuat kondisi yang lebih kompleks:

Operator Arti Penjelasan Contoh
AND DAN True hanya jika kedua syarat benar umur > 17 AND punya_sim
OR ATAU True jika salah satu (atau kedua) syarat benar nilai > 90 OR bonus
NOT BUKAN / KEBALIKAN Membalik nilai boolean (True → False, False → True) NOT hujan

Kapan masing-masing dipakai?

  • AND — Ketika semua syarat harus terpenuhi. Contoh: "Boleh masuk jika umur ≥ 17 DAN punya tiket."
  • OR — Ketika cukup salah satu syarat terpenuhi. Contoh: "Dapat diskon jika member ATAU beli lebih dari 3 item."
  • NOT — Ketika ingin membalik kondisi. Contoh: "Jika BUKAN hari libur, maka sekolah."

👀 Contoh: Blockly ↔ Python

Berikut contoh program yang meminta nilai ujian pengguna, lalu menentukan apakah lulus atau tidak:

🧩 Blok Blockly
print "Masukkan nilai:"
set nilai to read int
if nilai ≥ 75
print "Selamat, kamu lulus!"
else
print "Maaf, coba lagi."
🐍 Kode Python
print("Masukkan nilai:")
nilai = int(input())
if nilai >= 75:
    print("Selamat, kamu lulus!")
else:
    print("Maaf, coba lagi.")
🎓
Perhatikan Indentasi!

Di Python, kode yang berada di dalam blok if atau else harus menjorok ke kanan (indentasi). Ini menunjukkan bahwa kode tersebut adalah bagian dari percabangan. Blockly menangani indentasi ini secara otomatis untukmu.
